# Desktop Organizer

**Desktop Organizer** — это приложение для Windows, которое помогает навести порядок на рабочем столе, организуя файлы, папки и ярлыки в настраиваемые группы, называемые «виджетами». Хватит искать нужные файлы на захламленном рабочем столе — запускайте всё, что нужно, в пару кликов.

## Ключевые возможности

- **Создание виджетов** — группируйте элементы рабочего стола по проектам, категориям или любым другим критериям
- **Быстрый запуск** — открывайте файлы, папки и приложения прямо из виджетов
- **Пользовательские имена для элементов** — переименовывайте ярлыки и файлы в интерфейсе без изменения оригинальных файлов
- **Добавление файлов и папок** — вы можете добавлять любые папки и файлы, находящиеся на вашем жестком диске, в виджет
- **Горячие клавиши** — работайте быстрее с помощью комбинаций клавиш
- **Поддержка скринридеров** — NVDA, JAWS и экранный диктор
- **Мультиязычная поддержка** — переключение между доступными языками
- **Проверка обновлений** — всегда будьте в курсе новых версий

## Быстрый старт

### 1. Скачивание приложения

1. Перейдите на страницу **Релизы**
2. Скачайте архив с программой
3. Распакуйте архив в папку по вашему выбору

### 2. Первый запуск

1. Запустите файл `Desktop Organizer.exe`
2. При первом запуске появится диалог выбора языка
3. Выберите предпочитаемый язык
4. Нажмите **«Подтвердить»** для продолжения
5. Вы увидите главное окно программы

### 3. Создание виджета

1. Нажмите кнопку **«Создать виджет»** или комбинацию клавиш `Alt+C`
2. Введите название для виджета (например, «Работа», «Игры», «Проекты»)
3. Программа автоматически просканирует все ярлыки на рабочем столе
4. Выберите элементы, которые хотите добавить. Вы также можете добавить любые файлы и папки с вашего компьютера
5. Нажмите **«Создать»** для сохранения виджета

> Виджет создан — на рабочем столе автоматически появился его ярлык.

### 4. Открытие виджета

Существует два способа открыть виджет:

**Способ 1 — из главного окна:**

- Вы можете открывать виджеты прямо из главного окна программы, просто нажав на него

**Способ 2 — рекомендуемый:**

- Запустите только что появившийся ярлык на рабочем столе

### 5. Управление виджетами

**Редактирование виджета (добавление/удаление элементов):**

1. Выберите виджет в главном списке
2. Нажмите **«Редактировать виджет»** (или комбинацию клавиш `Alt+E`)
3. Откроется такое же окно, как при создании, где вы можете добавить или удалить элементы
4. Нажмите **«Сохранить изменения»**

**Удаление виджета:**

1. Выберите один или несколько виджетов в главном списке
2. Нажмите клавишу `Delete` или кнопку **«Удалить виджет»**
3. Подтвердите удаление при появлении запроса

**Переименование элемента внутри виджета:**

1. Откройте виджет
2. Выберите элемент, который хотите переименовать, и откройте контекстное меню (правой кнопкой мыши или клавишей `Menu` на клавиатуре)
3. Выберите **«Переименовать»** (или нажмите `F2`)
4. Введите новое отображаемое имя
5. Нажмите **«Переименовать»** для сохранения

## Горячие клавиши

| Комбинация | Действие |
| --- | --- |
| `Alt+C` | Создать новый виджет |
| `Alt+E` | Редактировать выбранный виджет |
| `Delete` | Удалить выбранный виджет |
| `Alt+S` | Открыть настройки |
| `Alt+Q` | Выйти из приложения |
| `F2` | Переименовать выбранный элемент (в окне виджета) |
| `Enter` | Запустить выбранный элемент (в окне виджета) |

## Настройки

Зайдите в настройки, нажав соответствующую кнопку в окне программы или сочетание клавиш `Alt+S`. Откроется окно со следующими пунктами:

### Язык

- Переключение языка интерфейса программы между поддерживаемыми языками
- Изменение вступает в силу сразу после выбора

### Спрашивать при выходе

- При включенной опции программа будет запрашивать подтверждение перед закрытием
- Предотвращает случайное закрытие приложения

### Проверять обновления

- При включенной опции программа будет автоматически проверять наличие новых версий при запуске
- Вы получите уведомление, если доступна новая версия

### Закрывать виджет при запуске

- При включенной опции окно виджета будет автоматически закрываться после запуска элемента
