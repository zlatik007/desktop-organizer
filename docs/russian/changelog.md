# Журнал изменений

Все  изменения этого проекта будут документироваться в этом файле.

соответствует [Семантическому версионированию](https://semver.org/lang/ru/).

## [2.0.0] - 2026-08-21

### Добавлено

- Теперь можно удалять элементы из виджета, не удаляя файлы с диска — отметьте их флажками и подтвердите удаление.
- Элементы внутри виджета теперь можно сортировать перетаскиванием или с помощью кнопок **«Вверх»** / **«Вниз»** и сочетаний клавиш `Alt+↑` / `Alt+↓`; новый порядок сохраняется.
- Ярлык для виджета теперь можно создать с помощью кнопки **«Создать ярлык»** в окне виджета или с помощью сочетания клавиш `Alt+K` в главном окне.
- При удалении виджета теперь можно выбрать: **«Удалить виджет полностью»** или **«Удалить только ярлык»**.

## [1.0.0] - 2026-08-16

### Добавлено

- Создание виджетов, группирующих элементы рабочего стола по проектам, категориям или любым другим критериям.
- Запуск файлов, папок и приложений прямо из виджетов.
- Задание пользовательских имён для элементов без переименования оригинальных файлов.
- Добавление любых файлов и папок с жёсткого диска в виджет.
- Использование горячих клавиш для частых действий.
- Работа со скринридерами (NVDA, JAWS, экранный диктор).
- Переключение языка интерфейса между доступными языками.
- Автоматическая проверка обновлений при запуске.
