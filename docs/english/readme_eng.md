# Desktop Organizer

Desktop Organizer is a Windows application that helps you declutter your desktop by organizing files, folders, and shortcuts into customizable groups called **"widgets"**. Stop searching through a messy desktop and start launching what you need with just a few clicks.

## Key Features

- **Create custom widgets** – Group desktop items by project, category, or any way you like
- **Launch items directly** – Open files, folders, or applications from within your widgets
- **Custom display names for items** – Rename shortcuts and files in the interface without affecting the original files
- **Add files and folders** – You can add any files and folders located on your hard drive to your widgets
- **Keyboard shortcuts** – Work faster with quick key combinations
- **Screen reader support** – NVDA, JAWS, and Narrator compatible
- **Multilingual support** – Switch between available languages
- **Auto-update check** – Always stay up to date

## Quick Start Guide

### 1. Download the Application

1. Go to the [Releases page](https://github.com/USERNAME/REPOSITORY/releases)
2. Download the archive with the program
3. Extract the archive to a folder of your choice

### 2. First Launch

1. Run the `Desktop Organizer.exe` file
2. On the first launch, you'll see a language selection dialog
3. Choose your preferred language
4. Click **"Confirm"** to continue
5. You will see the main window of the program

### 3. Creating a Widget

1. Click the **"Create Widget"** button, or press the keyboard shortcut `Alt+C`
2. Enter a name for your widget (e.g., "Work", "Games", "Projects")
3. The program will automatically scan all shortcuts on your desktop
4. Select the items you want to add. You can also add any files and folders from your computer
5. Click **"Create"** to save your widget

> Your widget has been created and a desktop shortcut has been added automatically.

### 4. Opening a Widget

There are two ways to open a widget:

**Method 1 - From the main window:**
- You can open widgets directly from the main program window by simply clicking on them

**Method 2 - Recommended:**
- Launch the shortcut that has just appeared on your desktop

### 5. Managing Your Widgets

**Edit a widget (add/remove items):**

1. Select the widget in the main list
2. Click **"Edit Widget"** (or press the keyboard shortcut `Alt+E`)
3. The same window as when creating a widget will open, where you can add or remove items
4. Click **"Save Changes"**

**Delete a widget:**

1. Select one or several widgets in the main list
2. Press `Delete` key or click the **"Delete Widget"** button
3. Confirm deletion when prompted

**Rename an item inside a widget:**

1. Open the widget
2. Select the item you want to rename and open the context menu (right-click or press the `Menu` key on your keyboard)
3. Select **"Rename"** (or press `F2`)
4. Enter the new display name
5. Click **"Rename"** to save

## Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Alt+C` | Create a new widget |
| `Alt+E` | Edit selected widget |
| `Delete` | Delete selected widget |
| `Alt+S` | Open Settings |
| `Alt+Q` | Exit application |
| `F2` | Rename selected item (in widget view) |
| `Enter` | Launch selected item (in widget view) |

## Settings

Go to Settings by clicking the corresponding button in the program window or using the keyboard shortcut `Alt+S`. A window will open with the following options:

**Language**

- Switch the program interface language between supported languages
- The change takes effect immediately after selection

**Ask on exit**

- When enabled, the program will ask for confirmation before closing
- Prevents accidental closure of the application

**Check for updates**

- When enabled, the program will automatically check for new versions on startup
- You will be notified if a new version is available

**Close widget on launch**

- When enabled, the widget window will automatically close after launching an item
