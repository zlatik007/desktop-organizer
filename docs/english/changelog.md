# Changelog

All notable changes to this project will be documented in this file.

This project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2026-08-21

### Added

- Items can now be removed from a widget without deleting the files on disk — mark them with checkboxes and confirm the deletion.
- Items inside a widget can now be reordered by drag & drop or with the **Move Up** / **Move Down** buttons using the `Alt+Up` / `Alt+Down` keyboard shortcuts; the new order is saved.
- A desktop shortcut for a widget can now be created with the **Create Shortcut** button in the widget window or with the `Alt+K` shortcut in the main window.
- When deleting a widget, you can now choose between **"Delete Widget Completely"** and **"Delete Only Shortcut"**.

## [1.0.0] - 2026-08-16

### Added

- Create custom widgets that group desktop items by project, category, or any other criteria.
- Launch files, folders, and applications directly from widgets.
- Give items custom display names without renaming the original files.
- Add any files and folders from your hard drive to a widget.
- Use keyboard shortcuts for common actions.
- Use the app with screen readers (NVDA, JAWS, Narrator).
- Switch the interface language between the available languages.
- Check for updates automatically on startup.
