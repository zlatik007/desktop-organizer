# Desktop Organizer

[English](README.md) | [Русский](README.ru.md)

**Desktop Organizer** — приложение для Windows, которое помогает навести порядок на рабочем столе, объединяя файлы, папки и ярлыки в настраиваемые группы — **«виджеты»**. Хватит искать нужные файлы на захламлённом рабочем столе: запускайте всё необходимое в пару кликов.

## Возможности

- **Создание виджетов** — группируйте элементы рабочего стола по проектам, категориям или любым другим критериям
- **Быстрый запуск** — открывайте файлы, папки и приложения прямо из виджетов
- **Пользовательские имена** — переименовывайте элементы в интерфейсе, не затрагивая оригинальные файлы
- **Добавление любых файлов и папок** — добавляйте в виджеты элементы со всего жёсткого диска
- **Горячие клавиши** — работайте быстрее с помощью комбинаций клавиш
- **Поддержка скринридеров** — NVDA, JAWS и экранный диктор
- **Мультиязычная поддержка** — переключение языка интерфейса
- **Проверка обновлений** — всегда будьте в курсе новых версий

## Установка

1. Перейдите на страницу [Releases](https://github.com/zlatik007/desktop_organizer/releases)
2. Скачайте архив с последней версией
3. Распакуйте архив в папку по вашему выбору
4. Запустите `Desktop Organizer.exe`

При первом запуске программа предложит выбрать язык интерфейса.
